Logo files:
  logo.svg              - main logo (dark background), used as default
  logo-dark.svg/.png    - logo on dark background (matches the AE panel vibe)
  logo-transparent.svg/.png - logo on transparent background (works on light or dark)

PNGs are rendered at 2x (1336x1600). Re-render from the SVGs if you need other sizes.
NOTE: the wordmark in these files uses a system sans-serif. For a pixel-perfect
match to the original mockup, open the SVG in Illustrator and swap the RECOMP text
for your exact font (convert to outlines before exporting).
